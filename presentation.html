Studio HelpDesk

Powering Brand Transformation through Process Excellence

The Current Bottleneck

Current State

  • Requests arrive via scattered emails, chats, and phone calls.
  • Missing briefs and incomplete requirements.
  • Unapproved requests bypassing management.
  • Unrealistic and subjective deadlines.

HelpDesk Solution

  • A single, mandatory portal for all requests.
  • Standardized inputs ensure brand compliance.
  • Upfront managerial approvals required.
  • Automated, objective SLA tracking.

Portal Entry & Dual-Workflow Gateway

1. Create New Request

  • Employee ID Login: Quick authentication using employee credentials.
  • Auto-Capture: Automatically populates department and contact profiles.
  • Fresh Ticket Generation: Immediately launches a clean task configuration block.

2. Track / Edit Request

  • Task Code Access: Direct entry via existing unique task code (e.g., REQ-CORPCOM-10001).
  • Instant Recovery: Instantly reloads previous ticket configuration and history.
  • Seamless Updates: Enables users to add delayed approvals or update active requirements.

The Employee Experience

  • Auto-filled Details: Requester and department information is captured automatically.
  • Clean Interface: User-friendly design aligned closely with Suzlon branding.
  • Zero Learning Curve: Guided dropdowns ensure employees only see relevant options.

Smart Timelines & Expectations

  • Automated SLAs: Deadlines calculate automatically based on the specific asset type (e.g., AV vs. Brochure).
  • 4 PM Cutoff: Requests submitted late automatically shift to the next working day.
  • Working Days Only: The system automatically skips weekends when calculating delivery targets.

Task Bundling & Targeted Attachments

  • Multi-Asset Requests: Submit multiple assets (e.g., Poster + Emailer) in one single ticket.
  • Task-Specific Uploads: Upload briefs, copy, and reference images directly to the relevant task block.

Approval & Final Submission

  • Flexible Workflows: Choose to upload managerial approvals immediately or defer them to a later date.
  • SLA Protection: Selecting "Will upload later" alerts the user that SLAs do not begin until the approval is provided.
  • Global Attachments: A single, unified drop zone for the final email approval covering all bundled tasks.

The Admin Superpowers (Studio View)

  • "On Behalf Of": Admins can unlock fields to submit tasks for leadership.
  • Live Dashboard: Instantly view, search, and load recent requests from the sidebar.
  • Audit Trail: Every edit is timestamped and tracked in the Activity Log for complete transparency.

Rollout & Next Steps

1. Phase 1: Pilot
Soft launch with frequent requesters (Corp Comm Internal Team) to test SLA accuracy and UI clarity.
2. Phase 2: Integration
Connect the portal to the broader Suzlon HelpDesk infrastructure.
3. Phase 3: Organization-Wide Go-Live
All corporate communication formally flows exclusively through the Studio HelpDesk.
